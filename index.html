Start NexaFlow locally

This React app cannot run by opening index.html as a file. Start the Vite development server so it can compile the JSX and connect to your local workspace.

  1. Install Node.js 20.19+ or 22.12+ from nodejs.org, then reopen your terminal.
  2. Open this project folder in VS Code and run npm install.
  3. Run npm run dev to start the React app and local data API together.
  4. Open http://127.0.0.1:5173/.

If your browser is showing this message from the file:// address, the app has not started yet. Keep both terminals open while using NexaFlow.
